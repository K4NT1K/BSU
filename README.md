# bsu

Coursework from the Faculty of Mechanics and Mathematics at Belarusian State University. Each folder is a standalone project.

## Projects

| Folder | Stack | Description |
| --- | --- | --- |
| [ToDoList](./ToDoList) | React, Vite | Class-component todo list: add, complete, delete |
| [FlashCards](./FlashCards) | React, Vite | Functional flashcards with learn mode and local storage |
| [SimonsSays](./SimonsSays) | HTML, CSS, JS | Simon Says memory game with best-score persistence |
| [Feed](./Feed) | HTML, CSS, JS | Searchable post feed with infinite scroll |
| [Colors](./Colors) | HTML, CSS, JS | RGB / CMY color playground |
| [Gallery](./Gallery) | HTML, CSS | Salvador Dalí painting gallery |
| [VideoAudio](./VideoAudio) | HTML, CSS, JS | Custom HTML5 video player |

## Run

React apps:

```bash
cd ToDoList   # or FlashCards
npm install
npm run dev
```

Static projects: open `index.html` in a browser (or serve the folder with any static server).
