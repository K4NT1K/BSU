# Feed

Лента постов на чистом JS: поиск, пагинация и бесконечная прокрутка.

- Поиск с debounce
- Кнопка «ещё» и Intersection Observer
- Состояния ошибки и пустого результата

Откройте `index.html` в браузере. Запросы к API постов описаны в `api.js`.
