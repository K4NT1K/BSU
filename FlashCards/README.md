# FlashCards

React + Vite flashcard trainer on functional components.

- Create, edit, and delete cards
- Flip / learn mode (all cards or unlearned only)
- Shuffle and mark as learned
- Persist decks in `localStorage`
- Seed from Open Trivia DB when storage is empty

## Setup

```bash
npm install
npm run dev
```

Build: `npm run build`. Preview: `npm run preview`.
