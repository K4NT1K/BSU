# FlashCards

Тренажёр карточек на React + Vite, функциональные компоненты.

- Создание, правка и удаление карточек
- Режим обучения (все или только невыученные)
- Перемешивание и отметка «выучено»
- Сохранение колоды в `localStorage`
- Стартовый набор из Open Trivia DB, если хранилище пустое

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`. Превью: `npm run preview`.
