# bsu

Учебные работы механико-математического факультета БГУ. Каждая папка — отдельный проект.

## Проекты

| Папка | Стек | Описание |
| --- | --- | --- |
| [ToDoList](./ToDoList) | React, Vite | Список дел на class-компонентах: добавление, выполнение, удаление |
| [FlashCards](./FlashCards) | React, Vite | Карточки на функциональных компонентах, режим обучения и localStorage |
| [SimonsSays](./SimonsSays) | HTML, CSS, JS | Игра Simon Says с сохранением рекорда |
| [Feed](./Feed) | HTML, CSS, JS | Лента постов с поиском и бесконечной прокруткой |
| [Colors](./Colors) | HTML, CSS, JS | Песочница цветов RGB / CMY |
| [Gallery](./Gallery) | HTML, CSS | Галерея картин Сальвадора Дали |
| [VideoAudio](./VideoAudio) | HTML, CSS, JS | Кастомный HTML5-плеер |

## Запуск

React-приложения:

```bash
cd ToDoList   # или FlashCards
npm install
npm run dev
```

Статические проекты: откройте `index.html` в браузере (или раздайте папку любым static-сервером).
